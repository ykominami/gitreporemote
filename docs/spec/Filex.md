# Filex — 外部仕様書

**モジュール:** `gitreporemote.filex`

## 概要

ファイルへの書き込みと標準出力への同時出力（ミラーリング）を行うシンプルなファイルライタ。
現在のエントリポイントからは使用されていない。

---

## クラス: `Filex`

### コンストラクタ

```python
Filex(path: str)
```

| 引数 | 型 | 説明 |
|------|----|------|
| `path` | `str` | 書き込み先ファイルのパス |

- コンストラクタ内でファイルを書き込みモード（`"w"`）で開く。

#### 初期状態

| 属性 | 型 | 説明 |
|------|----|------|
| `path` | `str` | ファイルパス |
| `f` | `IO` | 開いたファイルオブジェクト |

---

### メソッド

#### `print(data: str) -> None`

`data` をファイルに書き込み（`f.write(data)` のため改行は自動付与されない）、標準出力にも `print(data)` で出力する（標準出力側には改行が付与される）。
| 引数 | 型 | 説明 |
|------|----|------|
| `data` | `str` | 書き込むテキスト |

---

#### `close() -> None`

ファイルを閉じる。使用後は必ず呼び出すこと。

---

## 使用例

```python
from gitreporemote.filex import Filex

writer = Filex("output.txt")
writer.print("Hello, World!")
writer.close()
```

---

## 制約・注意事項

- ファイルは `"w"` モードで開くため、既存ファイルは上書きされる。
- エンコーディングを明示していないため、実行環境のデフォルト（通常 UTF-8）に依存する。
- `close()` を呼び忘れるとファイルがフラッシュされない可能性がある。
  `with` 文には非対応（`__enter__` / `__exit__` 未実装）。
- 現時点でどの CLI エントリポイントからも使用されていない。
